# HES interface review — 2 November 2026

Two review passes over `web/`:

- **web-design-guidelines** (Vercel Web Interface Guidelines): accessibility, focus, forms, animation, content.
- **ux-review**: Nielsen's 10 heuristics, WCAG 2.1 AA and the loading, empty, error and success states.

The previous pass (1 November) had already cleared the measured issues: contrast, labels, keyboard reach, focus rings, skip link and live regions. `tests/ui_audit.py` still reports the same clean result after these changes. This pass covers flow, feedback, error prevention and visual quality.

Backup of the interface before this pass: `_backup_before_ui_review_2026-11-02/`.

## What changed

| # | Finding (heuristic / guideline) | Severity | Fix |
|---|---|---|---|
| 1 | Fractions accepted silently. Typing `8` for an 8 % discount rate was sized into the study (error prevention). | Critical | Every fraction field has bounds and shows its percentage beside it (`= 8 %`). A value like `8` is caught at the field with "Enter this as a fraction: 8 % is 0.08". |
| 2 | Invalid numbers reached the engine. No inline errors, and focus did not go to the first error (guideline: errors inline, focus first error). | High | Inline check on every number field. Get resource data, Load profile, Run study and Recalculate design refuse invalid input, list the bad fields as links that go to each one, and focus the first. |
| 3 | Excluded technologies were shown as full pages of greyed-out fields, so the five that mattered were buried (aesthetic and minimalist design). | High | An excluded technology collapses to one line ("Include · not sized"), and its values are kept. The Components page is about a third shorter. |
| 4 | Two currency controls (cost basis and economics) could disagree (consistency). | High | Each one now updates the other. |
| 5 | Load profile, Load wind data and Recalculate design gave no busy state and could be fired twice (visibility of system status). | High | Every engine action marks its button busy and disables it until the reply arrives. |
| 6 | Leaving the page lost an unsaved study without warning (guideline: warn before navigating away). | High | A browser prompt appears if a study is on screen and unsaved. Saving clears it. |
| 7 | "Download hourly results (CSV)" actually exported one sample week (match with the real world). | High | Relabelled "Download sample week (CSV)". |
| 8 | Isolation table cut off its last column, and the PV isolator rating read "1479.0819479999998 V". | Medium | The table wraps its text columns, and the engine rounds the voltage (`ensys/sizing/protection.py`). |
| 9 | Results, Design and Diagrams did not say which of the N designs they described. Changing design meant going back to the chart (recognition over recall, user control). | Medium | A bar on each page reads "Design k of N · Recommended", with Previous / Next and a link back to the Pareto front. |
| 10 | Empty Results, Design and Diagrams pages showed one grey line. | Medium | Each now has an empty state with a checklist of what is missing and a button to go to the next step to do. |
| 11 | An indeterminate run bar, then a leftover full-width bar after the run finished. | Medium | Elapsed seconds are shown while the study runs, and the bar is removed when it finishes. |
| 12 | Results KPI tiles broke "USD / 296,124" over two lines and left one tile alone on a row. | Medium | Values stay on one line and the main figures sit in a 4 × 2 grid (2 × 4 on a phone). The duplicated heading became "Key figures". |
| 13 | Cost-breakdown labels were rotated even with four bars, and the SOC chart was plotted as 0-0.7 with no unit. | Low | Labels lie flat unless they are crowded, and SOC is plotted in %. |
| 14 | Native controls (select menus, scrollbars, file button) stayed light in dark mode, and the file button was unstyled. | Low | Added `color-scheme` and `theme-color` metadata and styled the file picker button to match the other buttons. |
| 15 | A scroll wheel over a focused number field changed its value without notice. | Low | The field loses focus on scroll, so the page scrolls instead. |
| 16 | Expert speed (flexibility and efficiency). | Low | `Ctrl+S` saves the project, `Ctrl+O` opens one and `Ctrl+Enter` runs the study on the Optimise page. |
| 17 | The Report page did not show what would be exported. | Low | A summary at the top shows the site, the selected design, its NPC and whether there is unsaved work. Report files are named after the project title. |
| 18 | Text fields offered browser autofill and spellcheck on CSV columns and data. Placeholders did not end in an ellipsis (guideline). | Low | `autocomplete="off"` and `spellcheck="false"` where appropriate, `inputmode="decimal"` on numbers, and placeholders end in "…". |

## Verification

- A full workflow (open example, run study, every page) in Chromium at 1440 px and 390 px, light and dark: no console errors.
- An interaction script checked the following: an empty state's button navigates to the right step; an invalid input blocks the run, its link focuses the field, and a fixed value lets the run go ahead; `Ctrl+Enter` runs the study; Previous / Next keep keyboard focus; the unsaved-work prompt fires before saving and clears after; `Ctrl+S` downloads the project; the report filename follows the title.
- `tests/ui_audit.py`: same clean result as the baseline.
- `pytest tests`: 256 passed.

## Not changed (deliberately)

- The sidebar credits block and the "Dark theme" text toggle are design choices, and they pass the audits.
- Wind turbine and the other optional technologies stay off by default.
- No step is locked in the navigation. The empty states guide instead of blocking.
