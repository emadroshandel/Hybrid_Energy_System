Site scale

          
Start here. The optimiser buys whole units, so the
            size of a PV block or a battery module decides what answers it can
            express at all — a 25 kWp block cannot describe a house. Choosing
            a scale moves the demand, the unit sizes, the grid connection and
            every per-unit cost together. Everything stays editable
            afterwards.

          

            
            
            
          

          

        


        

          
Load profile

          
An hourly demand series for one year. Paste CSV,
            upload a file, or use one of the built-in shapes. The engine
            accepts 8760 hourly values, 365 daily, or 12 monthly — anything
            shorter is expanded and the expansion is reported.
            Every value is read as kilowatts. A file in watts
            needs a scale factor of 0.001; nothing in the data reveals which
            it is.

Wind speed series optional

          
Only needed if the online source has no wind data,
            or you have measured data for the site. Renewables.ninja and
            met-station exports both work.

          
          

            
            
          

          
          

        

      


      
      

        
Define one unit of each technology and
          its cost. The optimiser decides how many of each to build — sizing
          in whole units because that is how equipment is actually bought.


        

          
Cost basis

          
Every cost below can be overwritten with your own
            quote. Any cost left at zero is filled from the
            regional library instead, so you only need to enter the figures
            you actually have.

          

            
            
            
          

          

        


        


        

          
More technologies

          
The engine models these too — each has a cost
            entry, a dispatch model and a diagram symbol. Enable any of them
            and the optimiser will size it alongside the rest.

Design basis

          
The electrical design is checked against IEC 60364 (parts 4-41,
            4-43, 5-52, 7-722), IEC 60909-0, IEC 62548-1, IEC 61724-1, IEC TS 62257,
            IEC 62933-2-1, IEEE 1013 / 1562 / 1547.9 and NFPA 855. Leave a temperature
            blank to take it from the site's hourly data.
